# Stage 3 report: pairwise compatibility audit and six-rule pilot

Generated by `scripts/stage3_report.py` from `freeze/stage3_summary.json` (built by `scripts/stage3_summary.py`). Every number below comes from that file.

## Method

- All 861 pairs of the 42 candidate types. For each pair, 50 parameter draws from the released default generators (seed 20261124); for each draw the builder gets up to 24 seeded attempts. A witness must pass both official verifiers and both frozen plain-meaning checks.
- A pair is **compatible** if any draw gives a witness; the success share is witnesses / 50 draws.
- Every pair without a witness was investigated: it is either a **proven conflict** (a written argument in `src/mife_ifb/stage3_proofs.py`; the library facts it relies on are tested) or **unsupported by the builder**. Both lists stay in the inventory; neither pair is co-sampled.
- `ratio:overlap` is run against task texts: 222 provisional base tasks (released prompts with the rule text removed), one task per draw. Stage 4 replaces them with the cleaned task list.
- The results come from one builder version for every pair (witness.py sha256 `1ae17eb3ee014335…`). Earlier passes (`full`, `rerun`) were used to find builder gaps and are not reported.
- D1 is empirical: "compatible" means the builder found a witness, and "unsupported" is not a proof of conflict.
