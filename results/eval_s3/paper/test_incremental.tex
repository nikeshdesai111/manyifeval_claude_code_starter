\section{Does a feature block add information? Comparisons 5--8}
\label{app:incremental}
Comparisons 5--7 add the hidden-state block H or the attention block A to a frozen text predictor (B1 or B2); comparison 8 adds A to B2+H and asks whether rule attention adds information beyond the hidden state. Each baseline keeps its cross-validated settings and only the added block's penalty is tuned on the training folds, on the same grid with ``off'' allowed (then the gain is zero by construction). Comparison 8 was added after the evaluation plan was written, at the project owner's request, and was fitted with this same recipe on the 50 training groups before any test scoring. All numbers are held-out test results on the 22 test groups.

Attention adds information in every setting: added to B2 (comparison 7) it lowers NLL by 0.0372 [0.0174, 0.0596] nats per outcome for Llama and 0.0236 [0.0084, 0.0420] for Qwen, and added to B2+H (comparison 8) by 0.0171 [0.0029, 0.0342] and 0.0128 [0.0033, 0.0228], so attention carries risk information that the hidden state does not. The hidden state added to B2 (comparison 6) helps for Llama (0.0236 [0.0075, 0.0416]) but not clearly for Qwen (0.0099 [$-0.0059$, 0.0276]); added to B1 (comparison 5) it raises AUROC for both generators. For matched changes (Table~\ref{tab:inc_e2}), adding attention makes forecasts of position changes worse (comparison 7: $-18.2$ and $-22.5$; comparison 8: $-17.0$ and $-9.6$), mirroring comparisons 3 and 4 in the main text.
