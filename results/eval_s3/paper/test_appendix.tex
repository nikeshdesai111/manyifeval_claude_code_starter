\subsection*{A4 --- Technical uncertainty and QC}
Probabilities are clipped to $[10^{-6}, 1-10^{-6}]$ before the logarithm (rows clipped: Llama 28; Qwen 1605). Every test prompt has 20 distinct verified responses (originals from run \texttt{main}, expansion prompts from run \texttt{expansion\_s3\_20261123}; one decoding-settings hash per generator). The frozen S3 refits were applied once; no sparse-type fallback head fired. New test hidden states and rule-span attention sums equal the frozen V1 features bit for bit on every original prompt checked, and the recomputed BGE-M3 embeddings equal the V1 cache. Bootstrap: 10,000 draws over the 22 test pools, seed 20261203, identical for every predictor, contrast and subgroup; intervals are pointwise and unadjusted. $t_{21}$ jackknife intervals and leave-one-pool-out ranges are in Table~\ref{tab:A1c}. Rule types with fewer than 8 contributing test pools: \texttt{english\_lowercase} (6), \texttt{capital\_word\_frequency} (6), \texttt{existence} (7), \texttt{number\_sentences} (7), \texttt{number\_words} (6), \texttt{english\_lowercase} (6), \texttt{capital\_word\_frequency} (6), \texttt{existence} (7), \texttt{number\_sentences} (7), \texttt{number\_words} (6). Independent recomputation checks (30/30 passed): direct NLL and \texttt{sklearn} AUROC on expanded binary outcomes; explicit-weight $\Delta$-MSE; structure block reproduces the stored training cache; test and training prompts disjoint.

\subsection*{C-C and D-D --- Matching, weighting and validation}
Matched pairs are built from manifest metadata only, before outcomes are read, and their counts equal the design counts for every factor and $k$. Companion: same pool, task, $k$, target rule and slot, every other slot identical, exactly one companion differs (earlier and later replacements both included; 7,920 / 35,640 / 22,176 / 7,920 prompt pairs at $k=2..5$). Task: each pool's 456 configurations appear with its three tasks, which belong to three different families, giving three unordered task pairs per target; no within-family matched comparison exists. Weights: equal per $k$ or transition, then pool, task, context and pair (the plan's proposed recipe). The noise-adjusted RMS estimator and its 22-pool interval were checked by simulation before test scoring (\texttt{tables/noise\_validation\_synthetic.csv}, 15 scenarios): the corrected square is unbiased, interval coverage is 91--100\%, and at an exact null the clipped root is biased upward by 0.5--1.1 points, so RMS values below about 1.5 points are not distinguishable from zero. Intervals are pointwise and unadjusted.
